# 现场服务器现状信息采集表

本表只记录服务器现状，不判断服务器是否合格。不要根据“8 核、64G、2T”等预期配置修改结果，以服务器实际显示内容为准。

## 1. 操作要求

- 优先使用具备 `sudo` 权限的账号。若只能使用 `root` 且系统没有 `sudo`，执行命令时删除开头的 `sudo`。
- 按表格顺序逐项执行命令或查看设备，把实际结果直接填写到本表的“现场填写”栏。
- 服务器终端不需要显示或输入中文；表中需要复制到终端的命令全部使用英文字符。
- 输出有多行时，只抄录“需记录内容”中指定的字段；表格空间不够时，可以另附一页文字记录，并注明对应序号。
- 出现 `command not found`、`Permission denied` 或其他报错时，把报错原文直接填入表格，不要自行处理。
- 对可能未安装的工具，先执行对应的 `command -v`，例如 `command -v docker`。没有输出时填写“未安装”，不要执行该行的后续命令。
- 不要安装或卸载软件，不要修改系统配置，不要重启服务器或服务。
- 不要记录服务器账号密码、远程管理口密码或其他凭据。
